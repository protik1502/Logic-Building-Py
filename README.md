# Logic Building with Loops (Before Starting DSA)

Welcome to my repository dedicated to mastering core programming logic using loops in **Python**! This repository serves as a foundational step to strengthen my problem-solving skills before diving deep into Data Structures and Algorithms (DSA).

## 🚀 Purpose
The goal of this repository is to build muscle memory for logic building, control flow, and iterative problem-solving by progressing through 8 structured phases of loop-based challenges.

## 🛠️ Tech Stack
* **Language:** Python 3.x 🐍

---

## 💡 Notes on Python Implementation
* **Do-While Loop Simulation:** Since Python does not have a native `do-while` loop, Phase 02 problems are solved using a `while True:` loop combined with an internal `if` condition and a `break` statement to ensure the block runs at least once.
